# Syllabus — concept frontier (example)

A fabricated syllabus showing the format — copy to your repo root as `syllabus.md`
and seed it from where you actually are. Read at Gate A and when planning study
sessions. Evidence lives in the learning log; this file only orders what comes next.
"→ next" marks the frontier per track; tracks advance independently, and a marker
moves only when the log shows the concept solid.

walked linearly.
